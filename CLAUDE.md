# Clayworks Studio

A ceramics tool for Rachel (New Orleans potter, product designer). Three jobs:
1. **Recipes** — turn hex codes or an inspiration photo into either Mason stain recipes (% of dry weight + grams for a batch) for a chosen clay body, cone and use (clay body / slip / glaze), or full **glaze recipes** (base totaling 100 + colorant additions, surface/opacity/food-safe options, grams for a dry batch).
1b. **Saved** — recipes saved from either mode or typed in ("Add your own", `+` lines = additions), with editable name, batch rescale and test notes. Stored as docs with `kind:"recipe"` in the same per-user store as shelves (`splitDocs`/`allDocs`), so they sync anywhere shelves do; rows are `{name,pct,add}` objects (no nested arrays).
2. **Shelves** — her studio inventory (stains, glazes, underglazes, clay bodies, chemicals), searchable against ~2,590 real products scraped from supplier sites, with add-from-photo, browse-a-line, and paste-a-list.

Rachel prefers short prompts and direct execution: make the change, verify it, report briefly. Don't over-ask.

## Backend: `worker/worker.js` (Cloudflare Worker)
- `POST /login {user,password}` → HMAC-signed session token (60 days). Passwords are PBKDF2-SHA256 (100k iters) with per-user salt, stored in the `USERS` secret: `{"rachel":{"salt","hash","cap":null},"grace":{"salt","hash","cap":3}}`.
- `POST /claude {prompt, images[], task}` → Anthropic Messages API. `task:"recipe"` → `claude-sonnet-5-5` ($2/$10 per M tokens); everything else → `claude-haiku-5-5` ($0.10/$0.50). Cost computed from `usage` and added to KV `spend:<user>:<week-start>`; weeks reset Monday 00:00 America/Chicago. Over cap → 429 `cap_reached` (checked before the call, so the last call can overshoot by a few cents).
- `GET /me` → spend/cap/reset. `GET|PUT /studio` → shelves JSON per user in KV `studio:<user>`.
- Ideas: `POST /feedback {text,page}` (any user, ≤30/day) stores in KV `feedback` and emails `FEEDBACK_TO` via Resend (`RESEND_API_KEY`, free plan, sender onboarding@resend.dev, which only delivers to the Resend account's own email) when both secrets exist. `GET|PUT /feedback` (mark done) only for `ADMIN_USERS` (wrangler.toml, default rachel); `/me` returns `admin`. UI: profile menu → Send an idea / Ideas inbox (shim).
- Bindings: KV `USAGE`; secrets `ANTHROPIC_API_KEY`, `SESSION_SECRET`, `USERS`, `FEEDBACK_TO` (set), `RESEND_API_KEY` (Rachel to add); vars `ALLOWED_ORIGIN`, `ADMIN_USERS`. See `worker/wrangler.toml`.
- Users/caps: regenerate with `node scripts/mkusers.mjs` (prints new passwords + USERS JSON) or edit caps in the USERS secret. Current values live in `private/` (gitignored — never commit it).

## Catalog pipeline
- `catalog/sources/catalog-<store>.json` — scraped per store (Oct 20 2026) via WebFetch: Laguna (818, complete), Sheffield Pottery (1,171, near complete), Alligator Clay (776, complete; Rachel's local New Orleans supplier), The Ceramic Shop (569, partial — site truncates paging), Bailey (202, partial — Magento nav swamps pages), Dogwood (0 — robots.txt blocks everything). Pasler (34, complete; pulled Oct 20 2026 from the public WooCommerce Store API `/wp-json/wc/store/v1/products`, tools/freight skipped).
- Item shape: `{kind: clay|glaze|underglaze|stain|chemical, brand, line, code, name, cone, url, source}`.
- `python3 catalog/merge_catalog.py` dedupes across stores (key = kind|brand|code, or kind|brand|line|name), normalizes Mason stains (brand "Mason", 4-digit code), merges `source` as "Store A, Store B". Then `python3 scripts/embed_catalog.py` inlines `catalog.json` into the page's `<script id="catalogData">` (inlined because a sibling-file fetch failed in the artifact viewer).
- **Glazy library**: `python3 -I scripts/glazy_subset.py <glazy_YYYYMMDD.yaml.gz>` → `catalog/glazy.json` (cone 5–6 incl. fractional cones like "5 1/2", State Production, Subtype Glaze*; 3,309 recipes, ~1 MB, compact: shared `materials` list + `g`/`x` index pairs), embedded as `<script id="glazyData">` by `embed_catalog.py`. Source is the GitHub export only (glazy.org robots.txt blocks AI agents and /api/, /export/; the export has **no photo field**, so Rachel chose Production-only over "has photo"). CC BY-NC-SA 4.0: every Glazy recipe shown/saved must credit author + link `glazy.org/recipes/<id>`. Shown in the Library tab; `glazyCandidates()` picks ~6–10 by surface/opacity/target-color words+colorants and feeds them into the glaze prompt (model returns `glazy_id`; tile shows "Adapted from Glazy"). Swatches: `--colors glazy-data-glazes-20211130.csv` adds `h` for 671 recipes (2021 rgb, usually photo-sampled, approximate; 0/255 placeholders dropped); library search accepts a hex (nearest first) and `glazyCandidates` boosts swatches near each target. Photos: the export has none and glazy.org forbids crawling/embedding (robots.txt; `frame-ancestors 'self'`). Rachel saves Glazy **Print Recipes** pages (≤50 recipes each, filter cone 5–6 + Production + Has Photo) to `~/Desktop/glazy/`; `python3 -I scripts/glazy_photos.py ~/Desktop/glazy` accumulates `catalog/glazy-photos.json` (`id → "06/906.<uniqid>.jpg"`; URL = `cdn.glazy.org/public/uploads/recipes/<bin>/l_<file>` + width params) and adds `p` to glazy.json; then `embed_catalog.py`. Her browser loads them lazily from Glazy's CDN with credit. Never bulk-harvest or bypass Glazy's 50-per-page limit. Raw export and CSV aren't committed.
- The page also has a small built-in `CATALOG`/`STAINS` list (Mason stains with approximate raw colors + body-stain notes) that external items merge into via `keyOf()`.

## Domain rules baked into recipes (keep these)
- Percentages are % of **dry** clay. Wet→dry: grams = lb × 453.6 × (1 − water%). Default water 20%; "really wet" ≈ 30%.
- Chrome-tin pinks/purples (6000–6006, 6381, 6385) are weak in clay bodies and need a zinc-free, calcium-bearing clear; they fade at cone 10/reduction. Prefer body-safe stains (Mason ref note 1): 6020, 6319, 6500, 6600, 6110, 63xx blues, etc.
- Keep total stain ≲12% in bodies (over-fluxing, shrinkage mismatch for nerikomi). Cobalt stains speck — sieve into slip first.
- Buff/dark/red bodies muddy pastels → suggest a white slip.
- Pasler stains (Amazon set) have unpublished chemistry — never use them in recipes.
